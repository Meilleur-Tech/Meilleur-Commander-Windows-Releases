# Sicherheit und Kompatibilität

Meilleur Commander für Windows wird getrennt für **x64** und **ARM64** angeboten. Wähle immer die passende Variante.

## Vertrauenswürdige Downloads

- Lade den Installer nur über die [offizielle Downloadseite](../README.md) herunter.
- Die Updatepakete werden anhand von Signaturen und Prüfsummen überprüft.
- Zu den Downloads gehört eine Datei **SHA256SUMS** mit Prüfsummen zur Kontrolle der heruntergeladenen Dateien.
- Für die Setup.exe wird derzeit keine Windows-Authenticode-Signatur behauptet. Die Signaturprüfung des Updateverfahrens ist davon getrennt.
- Updates werden über das für dein Gerät eingerichtete Gateway angeboten. Die bloße Verfügbarkeit einer Testversion bedeutet keine automatische Installation.

## Unterstützte Varianten

- **Windows x64:** stabile Version 2.2.3, Testversion 2.2.8
- **Windows ARM64:** Testversion 2.2.8

Vor einer produktiven Nutzung einer Testversion sollte die Kompatibilität im eigenen Umfeld überprüft werden.

## Verbindung

Für die Geräteverbindung wird ein gültiger Kopplungscode benötigt. Gib Codes und Zugangsdaten nicht an Dritte weiter. Bei Zertifikatsproblemen die Ursache beheben und Sicherheitsprüfungen nicht deaktivieren.
