# Meilleur Commander für Windows installieren

## Windows x64 und ARM64

1. Auf der [Downloadseite](../README.md) die Version für dein Gerät auswählen.
2. Die passende **Setup.exe** herunterladen.
3. Das Installationsprogramm starten und den Anweisungen folgen.
4. Meilleur Commander öffnen und die Adresse des bereitgestellten Gateways einstellen.
5. Den angezeigten Kopplungscode verwenden, um das Gerät zu verbinden.

Für den normalen Einsatz ist die stabile x64-Version **2.2.3** vorgesehen. **2.2.8** für x64 und ARM64 ist eine Testversion. Wähle ausschließlich die Variante, die zu deinem Windows-Gerät passt.

## Aktualisieren

In der Anwendung **Einstellungen → Update & Wartung → Nach Updates suchen** öffnen. Wenn für dein Gerät eine freigegebene neuere Version angeboten wird, den Installationshinweisen folgen. Die Updatepakete mit Endung ZIP sind nicht zum manuellen Entpacken vorgesehen.

## Vorherige Version wiederherstellen

Falls die Anwendung die Wiederherstellung einer früheren Version anbietet, diese Funktion nutzen. Eine ältere Version ist nur auswählbar, wenn eine vollständige vorherige Installation vorhanden ist.

## Benötigt

- Passendes Windows-Gerät (x64 oder ARM64)
- Netzwerkzugang zu deinem eingerichteten Commander-Gateway
- Berechtigung, das Setup auszuführen und das Gerät zu koppeln

Siehe auch [Fehlerbehebung](FEHLERBEHEBUNG.md).
