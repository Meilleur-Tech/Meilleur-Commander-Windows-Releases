# Meilleur Commander für Windows ARM64 2.2.8

**Testversion für Windows ARM64. Nicht für allgemeine produktive Installationen freigegeben.**

## Neu in dieser Version

Die Updateprüfung wurde verbessert: Wenn bereits ein Gateway eingestellt ist, kann der Windows-Client dort nach Updates suchen, auch wenn die erste Gerätekopplung noch nicht abgeschlossen ist. Bereits gekoppelte Geräte verwenden weiterhin ihr eingerichtetes Gateway.

## Herunterladen und installieren

- **Setup:** `Meilleur-Commander-Client-Windows-arm64-2.2.8-Setup.exe`
- **Updatepaket:** `Meilleur-Commander-Client-Windows-arm64-2.2.8.zip`

Nur auf Windows-Geräten mit ARM64-Prozessor installieren. Updates über **Einstellungen → Update & Wartung → Nach Updates suchen** prüfen. Das ZIP-Paket nicht manuell entpacken.

## Bekannte Einschränkungen

Diese Version befindet sich in der Erprobung. Eine vollständige Freigabe aller Update-, Wiederherstellungs- und Anzeigeabläufe ist für diese Testversion noch nicht zugesagt.
