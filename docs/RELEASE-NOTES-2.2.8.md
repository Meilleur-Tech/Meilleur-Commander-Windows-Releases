# Meilleur Commander für Windows x64 2.2.8

**Testversion. Nicht die aktuelle stabile Version.**

## Neu in dieser Version

Die Updateprüfung wurde verbessert: Wenn bereits ein Gateway eingestellt ist, kann der Windows-Client dort nach Updates suchen, auch wenn die erste Gerätekopplung noch nicht abgeschlossen ist. Bereits gekoppelte Geräte verwenden weiterhin ihr eingerichtetes Gateway.

## Herunterladen und installieren

- **Setup:** `Meilleur-Commander-Client-Windows-x86_64-2.2.8-Setup.exe`
- **Updatepaket:** `Meilleur-Commander-Client-Windows-x86_64-2.2.8.zip`

Das Setup für Windows x64 herunterladen und starten. Updates anschließend über **Einstellungen → Update & Wartung → Nach Updates suchen** prüfen. Das ZIP-Paket dient dem Updateverfahren und muss nicht manuell entpackt werden.

## Bekannte Einschränkungen

Diese Version dient weiterhin der Erprobung. Eine vollständige Freigabe aller Update-, Wiederherstellungs- und Anzeigeabläufe ist für diese Testversion nicht zugesagt. Für reguläre x64-Installationen die stabile Version **2.2.3** verwenden.
