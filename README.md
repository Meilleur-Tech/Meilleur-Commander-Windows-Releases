# Fabric Commander für Windows

Hier findest du die Windows-Downloads und Anleitungen für Fabric Commander.

|---|---|---|

| **Windows ARM64, Version 2.2.10** | Aktuelle stabile ARM64-Version | [ARM64 herunterladen](https://github.com/Meilleur-Tech/Meilleur-Commander-Windows-Releases/releases/tag/windows-client-arm64-v2.2.10) |

## Funktionen

- Native Windows-Anwendung mit grafischer Oberfläche
- Verbindung über den konfigurierten Fabric-Commander-Verbindungsweg
- Geräteverbindung über einen Kopplungscode
- Updateprüfung aus der Anwendung über signierte öffentliche Stable-Kanäle, auch wenn das Gateway vorübergehend nicht erreichbar ist
- Wiederherstellung der vorherigen Programmversion, sofern verfügbar

## Installation

1. Den passenden Download für **x64** oder **ARM64** öffnen.
2. Die Datei mit der Endung **Setup.exe** herunterladen und starten.
3. Den angebotenen Verbindungsweg auswählen und den Kopplungscode verwenden.
4. Updates später in der Anwendung unter **Einstellungen → Update & Wartung → Nach Updates suchen** prüfen.

ZIP-Dateien sind Updatepakete für die Anwendung und normalerweise nicht für eine manuelle Installation gedacht.
